# AotterTrek SDK for Flutter

Flutter packages for serving [AotterTrek](https://aotter.net) ads.

| Package | Version | Purpose |
|---|---|---|
| [`trek_gma_mediation`](packages/trek_gma_mediation) | 0.1.0 | AotterTrek ads through Google Mobile Ads mediation (AdMob and Ad Manager), with built-in native ad layouts that size themselves to each creative |
| `trek_ads` | In development | AotterTrek ads straight from a Dart API, without Google Mobile Ads |
