# AotterTrek SDK for Flutter

Flutter packages for serving [AotterTrek](https://aotter.net) ads.

| Package | Version | Purpose |
|---|---|---|
| [`trek_gma_mediation`](packages/trek_gma_mediation) | 0.1.1 | AotterTrek ads through Google Mobile Ads mediation (AdMob and Ad Manager), with built-in native ad layouts that size themselves to each creative |
| [`trek_ads`](packages/trek_ads) | 0.1.1 | AotterTrek ads straight from the AotterTrek SDKs, without Google Mobile Ads, with built-in native ad layouts that size themselves to each creative |
